# StackBench 页面布局建议

整体采用 **“顶栏 + 左侧分类导航 + 主内容区”** 的工作台布局，工具页统一为 **“输入 / 输出双栏”**，复杂工具再局部扩展。目标是：搜索优先、键盘可达、工具页零学习成本。

---

## 1. 整体信息架构

```text
┌──────────────────────────────────────────────────────────┐
│ 顶栏：Logo | 全局搜索(Cmd+K) | Agent状态 | 主题 | 设置      │
├──────────┬───────────────────────────────────────────────┤
│ 左侧导航  │  主内容区                                      │
│ 收藏      │                                               │
│ 最近使用  │  首页 / 工具页 / 设置页                        │
│ 分类列表  │                                               │
└──────────┴───────────────────────────────────────────────┘
```

- **顶栏固定**，高度 56px，始终可见。
- **左侧导航可折叠**，宽度 220px，折叠后 56px 仅显示图标。
- 主内容区最大宽度 1440px，工具页可全宽。
- 不做多级菜单，分类下直接列工具，靠搜索和收藏解决长列表。

---

## 2. 顶栏布局

```text
[Logo StackBench]  [ 🔍 搜索工具...  Cmd+K ]   [● Agent 在线] [🌙] [⚙]
```

- Logo 点击回首页。
- 搜索框占中间弹性宽度，点击或 `Cmd/Ctrl+K` 聚焦，聚焦后浮层展示命令面板。
- **Agent 状态指示**：绿点在线 / 灰点未启动 / 红点异常，点击弹出说明与启动命令，不自动降级上传。
- 主题切换、设置入口靠右。
- 移动端收起为：Logo + 搜索图标 + 菜单图标。

## 3. 首页布局

```text
┌──────────────────────────────────────────────────────────┐
│  搜索框（大号，居中偏上）  Cmd+K                           │
│  常用关键词快捷入口：json / jwt / diff / color / http ...  │
├──────────────────────────────────────────────────────────┤
│  收藏（横向卡片，最多 8 个）                               │
├──────────────────────────────────────────────────────────┤
│  最近使用（横向卡片或列表，最多 6 个）                     │
├──────────────────────────────────────────────────────────┤
│  分类工具网格                                              │
│  [数据格式] [编码转换] [时间任务] [安全鉴权]              │
│  [文本处理] [API 调试] [配置网络] [UI 视觉] [通用]        │
│  每个分类下工具卡片：名称 / 简述 / 执行位置徽标            │
└──────────────────────────────────────────────────────────┘
```

建议：

- 首屏只放 **搜索 + 收藏 + 最近使用**，工具网格在下方。
- 工具卡片统一高度，显示 **执行位置徽标**（本地 / Worker / Agent）和敏感标识。
- 分类网格响应式：桌面 4 列，平板 2–3 列，移动 1 列。
- 空收藏/空最近使用展示引导文案，不占大块空白。

## 4. 工具页通用布局

### 4.1 标准双栏（大多数工具）

```text
┌──────────────────────────────────────────────────────────┐
│ 面包屑：首页 / 数据格式 / JSON 格式化      [★收藏] [分享] │
├──────────────────────────────────────────────────────────┤
│ 工具标题 + 简述 + 执行位置徽标                             │
├───────────────────────────┬──────────────────────────────┤
│ 输入区                     │ 输出区                        │
│ [工具栏: 示例|清空|格式]   │ [工具栏: 复制|下载|视图切换]  │
│                           │                              │
│ Monaco / textarea         │ 结果展示 / 错误提示           │
│                           │                              │
├───────────────────────────┴──────────────────────────────┤
│ 操作栏：[执行/转换]  状态：成功/失败  耗时  字符数         │
├──────────────────────────────────────────────────────────┤
│ 说明区：用法、示例、安全提示（可折叠）                     │
└──────────────────────────────────────────────────────────┘
```

- 左右栏 **50:50**，可拖拽分隔条调整比例，比例记忆在本地。
- 输入输出各自独立工具栏，避免操作混淆。
- 主操作按钮固定在操作栏，不随内容滚动丢失。
- 错误提示就近显示在输出区顶部，含行号/列号/原因/建议。
- 说明区默认折叠，首次访问展开。

### 4.2 单栏流式（轻量工具）

适用于时间戳、UUID、Hash、单位转换等：

```text
┌────────────────────────────────────────────┐
│ 标题 + 简述 + 执行位置徽标                  │
├────────────────────────────────────────────┤
│ 参数表单（紧凑两列）                        │
├────────────────────────────────────────────┤
│ 结果卡片（大字展示 + 复制）                 │
├────────────────────────────────────────────┤
│ 说明与示例                                  │
└────────────────────────────────────────────┘
```

### 4.3 特殊工具布局

| 工具 | 布局建议 |
|---|---|
| 文本 Diff | 全宽，顶部选项栏（并排/统一、忽略空白），下方左右对比或统一视图 |
| 正则测试 | 上：表达式 + flags + 常用模板；下左：测试文本；下右：匹配列表/分组/替换预览 |
| HTTP 调试 | 左：请求方法/URL/Headers/Body 分区 Tab；右：响应状态/头/体/耗时；底部历史抽屉 |
| JSON Schema 校验 | 上：Schema 与数据双栏；下：校验结果列表，错误可点击定位 |
| 颜色/调色板 | 左：颜色输入与色阶；右：实时预览与 CSS 变量输出 |
| CSS 阴影/布局生成 | 左：参数控件；右：实时预览 + 生成 CSS，可复制 |
| 图片转 Base64 | 左：上传/拖拽 + 压缩参数；右：预览、前后大小对比、Base64 输出 |
| SVG 预览 | 左：源码；右：沙箱预览 + 基础信息；顶部格式化/压缩 |
| OpenAPI 预览 | 左：接口树；右：接口详情与 Schema；顶部导入与校验结果 |

## 5. 命令面板布局

```text
┌──────────────────────────────────────────┐
│ 🔍 输入工具名 / 关键词...                 │
├──────────────────────────────────────────┤
│ 最近使用                                  │
│  JSON 格式化        数据格式   本地       │
│  JWT 解析           安全鉴权   本地       │
│ 搜索结果                                  │
│  HTTP 请求调试      API 调试   Agent      │
│  颜色转换           UI 视觉    本地       │
├──────────────────────────────────────────┤
│ ↑↓ 选择   Enter 打开   Esc 关闭           │
└──────────────────────────────────────────┘
```

- 居中浮层，宽度 640px，最大高度 70vh。
- 结果项右侧固定显示 **分类 + 执行位置徽标**。
- 支持分组：最近使用 / 收藏 / 搜索结果。
- 键盘优先，鼠标可用。

## 6. 左侧导航布局

```text
[★ 收藏]
[🕘 最近使用]
──────────
数据格式
编码转换
时间与任务
安全与鉴权
文本处理
API 调试
配置与网络
UI 与视觉
通用工具
──────────
[⚙ 设置]
```

- 分类可展开/收起，默认展开当前分类。
- 当前工具高亮，父分类高亮。
- 收藏与最近使用置顶，避免高频工具沉底。
- 窄屏时导航收进抽屉，顶栏出现菜单按钮。

## 7. 全局状态与反馈位置

| 元素 | 位置 | 说明 |
|---|---|---|
| Agent 状态 | 顶栏右侧 | 点击查看启动方式与连接测试 |
| 复制反馈 | 按钮附近 toast | “已复制”，2 秒消失 |
| 执行状态 | 工具页操作栏 | 成功/失败/进行中 |
| 错误提示 | 输出区顶部 | 位置、原因、建议 |
| 分享链接 | 工具页右上 | 生成后弹窗展示并复制 |
| 敏感提示 | 工具标题下方 | “本地处理，不上传” |

---

## 8. 响应式规则

- **≥1280px**：左侧导航 + 双栏工具页全展示。
- **768–1279px**：导航可折叠；双栏可切换为上下堆叠。
- **<768px**：导航抽屉；工具页单栏上下堆叠；操作栏吸底；命令面板全屏。
- 图片、Diff、HTTP 调试在移动端优先保证可用，不追求完全对齐。

---

## 9. 布局规范建议

- 间距基数 4px，常用 8/12/16/24/32。
- 圆角统一 8px，卡片 12px。
- 输入输出区最小高度 320px，可拖拽调整。
- 工具卡片固定结构：图标/名称/简述/徽标，保证网格整齐。
- 所有可复制结果提供一键复制，复制内容为可直接使用的文本。
- 深色模式跟随系统，可手动切换并本地记忆。

---

## 10. 建议优先落地的页面

1. **顶栏 + 左侧导航 + 首页**
2. **命令面板**
3. **标准双栏工具页模板**
4. **单栏轻量工具页模板**
5. **Diff / HTTP 调试 / 颜色 三个特殊布局**

这样先统一骨架，后续工具按模板接入，避免每个工具各做一套布局。
