# 全栈工程师常用工具集 功能需求说明书

**版本**：V1.0  
**产品定位**：面向全栈工程师的常用工具集，统一入口、默认本地处理、支持分享与本地 Agent 扩展。项目本身可采用 AI 辅助开发，但产品功能不包含 AI 开发工具。  
**优先级**：仅包含 P0、P1；不包含团队与平台化能力。

---

## 1. 文档目的

本文档定义全栈工程师常用工具集的功能范围、功能优先级、详细功能需求、执行位置、异常规则与验收标准，作为产品设计、开发、测试和验收的依据。

---

## 2. 产品目标

1. 为全栈工程师提供统一的高频工具入口，减少零散网站切换。
2. 默认在浏览器本地处理数据，敏感数据不上传。
3. 需要密钥、证书、内网请求的能力通过本地 Agent 执行。
4. 工具参数可通过链接分享，便于复现和沟通。
5. 工具采用统一注册协议，便于扩展、测试和 AI 辅助开发维护。

---

## 3. 范围

### 3.1 包含

- P0：核心刚需工具与统一框架能力。
- P1：效率增强工具。
- 本地收藏、最近使用、分享链接、全局搜索。
- 浏览器本地执行、Web Worker 大文本处理、本地 Agent 执行。
- 工具注册协议、统一交互、错误提示、基础非功能要求。

### 3.2 不包含

- 团队收藏与共享。
- 插件市场、工具市场。
- SSO、权限、审计。
- 使用统计与排行。
- 私有化部署管理后台。
- 团队级 Prompt/请求共享。
- 任何需要将敏感输入上传云端的功能。

---

## 4. 用户与典型场景

**目标用户**：前端、后端、全栈工程师、测试工程师。

**典型场景**：

- 联调接口：JSON 格式化、JSON Schema 校验、HTTP 请求调试、curl 转代码。
- 配置处理：JSON/YAML 互转、`.env` 格式化、Docker/K8s YAML 校验。
- 鉴权排查：JWT 解析、HMAC/JWT 签名验签、证书解析。
- 日常编码：Base64/URL 编解码、Hash、UUID、正则测试、文本 Diff、时间戳/Cron。
- 后端排查：SQL 格式化、日志解析、CIDR/端口/MIME/HTTP 状态码。
- 前端处理：图片转 Base64、颜色转换、Markdown/CSS 格式化。

## 5. 总体功能需求

### 5.1 统一入口

- 首页展示搜索框、工具分类、最近使用、本地收藏。
- 工具按类别分组：数据格式、编码转换、时间与任务、安全与鉴权、文本处理、API 调试、配置与网络、前端资源、通用工具。
- 每个工具卡片展示名称、简述、执行位置标识。

### 5.2 全局搜索与命令面板

- 支持 `Ctrl/Cmd + K` 打开命令面板。
- 支持按工具名称、关键词、别名、分类搜索。
- 支持键盘上下选择、回车打开、Esc 关闭。
- 结果排序综合考虑：完全匹配、最近使用、本地收藏、关键词匹配。
- 无结果时展示提示和反馈入口说明。

### 5.3 工具页统一交互

- 统一布局：输入区、输出区、操作栏、说明区。
- 操作栏至少包含：执行/转换、清空、复制结果、加载示例、分享链接。
- 错误提示包含错误位置、原因、修复建议。
- 支持深色/浅色模式。
- 支持键盘操作和复制成功提示。

### 5.4 本地收藏与最近使用

- 收藏和最近使用仅保存在浏览器本地。
- 支持收藏/取消收藏。
- 最近使用按时间倒序，可清空。
- 不涉及团队共享。

### 5.5 分享链接

- 非敏感工具可将输入参数编码到 URL，打开后恢复参数。
- 敏感工具或敏感字段不得写入 URL。
- 分享链接生成前需进行敏感字段过滤。
- 支持一键复制分享链接。

### 5.6 执行位置标识与安全提示

每个工具必须声明执行位置：

- **浏览器本地**：输入不离开浏览器。
- **浏览器 + Web Worker**：大文本处理，不离开浏览器。
- **本地 Agent**：通过 `127.0.0.1` 本地服务执行，敏感数据不上传外网。
- **浏览器/本地**：优先本地，必要时调用本地 Agent。

工具页需展示执行位置和安全说明。

### 5.7 工具注册与扩展

每个工具必须注册以下信息：

- `id`、名称、分类、关键词、别名、简述。
- 执行位置、是否敏感、是否可分享。
- 输入 Schema、输出 Schema、示例数据。
- 组件入口、核心处理函数。

新增工具不得修改搜索、路由、收藏等通用逻辑。

### 5.8 错误与空状态

- 输入为空时展示示例或操作提示。
- 转换失败时保留原输入，展示可理解错误。
- 本地 Agent 不可用时提示安装/启动方式，不自动降级上传。

## 7. P0 详细功能需求

### FR-P0-01 全局搜索 / 命令面板

**功能描述**：提供统一搜索入口，快速定位工具。

**需求细则**：

1. 支持 `Ctrl/Cmd + K` 打开命令面板。
2. 搜索范围包括工具名称、关键词、别名、分类。
3. 结果展示工具名称、简述、执行位置标识。
4. 支持键盘上下选择、回车打开、Esc 关闭。
5. 排序优先级：完全匹配 > 关键词匹配 > 最近使用 > 本地收藏。
6. 无结果时展示“未找到工具”。

**验收标准**：

- 输入工具名称或关键词能在 100ms 内展示结果。
- 键盘可完成打开工具全流程。
- 无结果状态正常展示。

### FR-P0-02 工具注册与分享链接

**功能描述**：统一工具注册协议，并支持非敏感参数分享。

**需求细则**：

1. 每个工具注册 `id/name/category/keywords/executor/sensitive/shareable/inputSchema/outputSchema/examples`。
2. 搜索索引、路由、工具说明由注册信息自动生成。
3. 非敏感工具支持将输入参数编码到 URL。
4. 打开分享链接后自动恢复工具和输入参数。
5. 敏感工具不得生成包含输入的分享链接。
6. 分享链接只包含声明为可分享的字段。

**验收标准**：

- 新增工具只需添加注册信息和实现，不改通用搜索/路由。
- 分享链接可恢复非敏感参数。
- 敏感字段不会出现在 URL 中。

### FR-P0-03 JSON 格式化 / 压缩 / 校验

**功能描述**：处理 JSON 文本的格式化、压缩和语法校验。

**需求细则**：

1. 支持格式化缩进 2 空格、4 空格、Tab。
2. 支持压缩为单行。
3. 校验失败时展示错误行号、列号、原因。
4. 支持复制结果、清空、加载示例。
5. 大文本使用 Web Worker，避免阻塞界面。
6. 支持 5MB 以内 JSON 文本处理。

**验收标准**：

- 正常 JSON 可格式化/压缩。
- 错误 JSON 能定位错误位置。
- 5MB JSON 处理时界面保持可交互。

### FR-P0-04 JSON ↔ YAML 互转

**功能描述**：JSON 与 YAML 双向转换。

**需求细则**：

1. 支持 JSON 转 YAML、YAML 转 JSON。
2. 保留字符串、数字、布尔、数组、对象等基本类型。
3. 转换失败展示错误位置和原因。
4. 支持复制结果、清空、加载示例。
5. 大文本使用 Web Worker。

**验收标准**：

- 常见配置结构双向转换正确。
- 非法输入有明确错误提示。
- 大文本不阻塞界面。

### FR-P0-05 时间戳转换 / Cron 解析

**功能描述**：时间戳与日期互转，Cron 表达式解析。

**需求细则**：

1. 时间戳支持秒/毫秒自动识别，也可手动指定。
2. 展示本地时间、UTC 时间、ISO 8601。
3. 支持当前时间一键填入。
4. Cron 支持 5 字段和 6 字段解析。
5. 展示未来若干次执行时间。
6. 提供常用 Cron 模板。
7. 非法表达式展示错误原因。

**验收标准**：

- 秒/毫秒时间戳转换正确。
- Cron 表达式可展示未来执行时间。
- 非法输入有错误提示。

### FR-P0-06 Base64 / URL 编解码

**功能描述**：提供 Base64 和 URL 编解码。

**需求细则**：

1. Base64 支持 UTF-8 编码解码。
2. 支持标准 Base64 和 URL-safe Base64。
3. URL 支持 `encodeURIComponent/decodeURIComponent`。
4. 解码失败展示错误原因。
5. 支持复制结果和清空。

**验收标准**：

- 中文、英文、特殊字符编解码正确。
- 非法 Base64/URL 编码有错误提示。
- URL-safe 模式可正确转换。

### FR-P0-07 Hash / UUID 生成

**功能描述**：计算文本 Hash，生成 UUID。

**需求细则**：

1. Hash 支持 MD5、SHA1、SHA256、SHA512。
2. Hash 输入为文本，结果支持大小写展示。
3. UUID 支持 v4、v7。
4. 支持批量生成，数量可配置。
5. 支持是否包含连字符、大小写选择。
6. 支持复制结果。

**验收标准**：

- Hash 结果与标准算法一致。
- UUID 格式正确，批量生成可用。
- 复制和清空正常。

### FR-P0-08 JWT 解析

**功能描述**：解析 JWT 的 Header 和 Payload，不验签。

**需求细则**：

1. 支持三段式 JWT 解析。
2. 展示 Header、Payload、签名部分。
3. 展示签发时间、过期时间，并高亮已过期。
4. 解码使用 Base64URL。
5. 解析失败展示具体原因。
6. 页面明确提示“仅解析，不验签”。

**验收标准**：

- 合法 JWT 可展示 Header/Payload。
- 过期 JWT 有过期标识。
- 非法 JWT 有错误提示。

### FR-P0-09 正则测试

**功能描述**：测试正则匹配、分组和替换。

**需求细则**：

1. 支持正则表达式和 flags 输入。
2. 展示匹配结果列表、匹配位置、分组内容。
3. 支持替换预览。
4. 提供常用正则模板。
5. 非法正则展示错误原因。
6. 对明显高风险表达式给出性能提示。

**验收标准**：

- 匹配、分组、替换结果正确。
- 非法正则有错误提示。
- 常用模板可一键填入。

### FR-P0-10 文本 Diff

**功能描述**：对比两段文本差异。

**需求细则**：

1. 支持左右两段文本输入。
2. 展示行级差异，区分新增、删除、修改。
3. 支持并排视图和统一视图。
4. 支持忽略空白选项。
5. 大文本使用 Web Worker。
6. 支持复制差异结果。

**验收标准**：

- 常见文本差异展示正确。
- 大文本对比不阻塞界面。
- 忽略空白选项生效。

### FR-P0-11 curl 转代码片段

**功能描述**：将 curl 命令转换为常用代码片段。

**需求细则**：

1. 解析 curl 的 method、URL、headers、body。
2. 支持输出 fetch、axios、Go、Python、Java 代码。
3. 支持复制生成代码。
4. 对不支持参数给出提示。
5. 解析失败展示原因。

**验收标准**：

- 常见 GET/POST curl 可正确转换。
- 多语言输出格式正确。
- 不支持参数有提示。

### FR-P0-12 HTTP 请求调试

**功能描述**：通过本地 Agent 发送 HTTP 请求并查看响应。

**需求细则**：

1. 支持 GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS。
2. 支持 URL、Query、Headers、Body。
3. 支持超时设置和重试次数设置。
4. 展示状态码、响应头、响应体、耗时、大小。
5. JSON 响应支持格式化展示。
6. 请求历史仅保存在本地。
7. 本地 Agent 未启动时提示启动方式，不上传请求。
8. 本地 Agent 仅监听 `127.0.0.1`，校验 Origin 和随机 token。

**验收标准**：

- 常见 HTTP 请求可发送并展示响应。
- 超时、错误状态码、网络错误有提示。
- Agent 未启动时不泄露输入。
- 非本地来源无法调用 Agent。

### FR-P0-13 JSON Schema 校验

**功能描述**：使用 JSON Schema 校验 JSON 数据。

**需求细则**：

1. 提供 Schema 输入区和数据输入区。
2. 展示校验通过/失败。
3. 失败时展示错误路径、原因。
4. 支持复制错误信息。
5. 支持加载示例。

**验收标准**：

- 合法数据校验通过。
- 非法数据展示错误路径。
- 示例可一键加载。

### FR-P0-14 `.env` / 配置格式化

**功能描述**：整理 `.env` 配置文本。

**需求细则**：

1. 解析 `KEY=VALUE` 行，保留注释和空行规则。
2. 支持按 key 排序、去除重复 key 提示。
3. 支持敏感 key 脱敏展示。
4. 支持复制和导出整理后文本。
5. 格式错误展示行号。

**验收标准**：

- 常见 `.env` 可格式化。
- 重复 key 有提示。
- 脱敏显示生效。

## 9. 非功能需求

### 9.1 安全与隐私

1. 默认浏览器本地处理，不上传输入数据。
2. 敏感工具必须通过本地 Agent 执行。
3. 本地 Agent 仅监听 `127.0.0.1`，使用随机 token，校验 Origin。
4. 不记录用户输入内容到服务端日志。
5. 分享链接不得包含敏感字段。
6. 密钥、证书、Token 不写入 URL，不明文持久化到 Web 存储。
7. Agent 未启动时不得自动降级为云端上传。

### 9.2 性能

1. 本地搜索响应时间不超过 100ms。
2. JSON、Diff、日志等大文本处理使用 Web Worker。
3. 5MB 文本处理时界面保持可交互。
4. 工具页首屏加载不因非当前工具代码明显阻塞。

### 9.3 可测试与可维护

1. 每个工具的核心转换逻辑为纯函数，与 UI 分离。
2. 每个工具至少覆盖正常输入、边界输入、错误输入测试。
3. 工具注册信息驱动搜索、路由、说明和示例。
4. 新增工具不需要修改通用搜索、路由、收藏逻辑。
5. 工具说明和示例可从注册信息生成。

### 9.4 兼容与可用性

1. 支持 Chrome、Edge、Firefox、Safari 最近两个大版本。
2. 支持浅色/深色模式。
3. 关键操作支持键盘完成。
4. 错误提示包含位置、原因和建议。
5. 复制、清空、示例加载等操作有明确反馈。

## 10. 总体验收标准

1. P0 全部功能可用，P1 功能按优先级逐步提供。
2. 每个 P0 工具至少有示例数据、错误提示和验收用例。
3. 全局搜索、本地收藏、最近使用、分享链接可用。
4. 敏感工具通过本地 Agent 执行，未启动时明确提示且不上传数据。
5. 5MB JSON/Diff 处理不阻塞界面。
6. 分享链接不包含敏感字段。
7. 不包含团队收藏、插件市场、SSO、权限审计、使用统计、私有化部署后台等 P2 能力。
8. 新增工具遵循统一注册协议，具备核心逻辑单测。
