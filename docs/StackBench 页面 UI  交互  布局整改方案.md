# StackBench 页面 UI / 交互 / 布局整改方案

> 适用范围：`index.html` 页面骨架、`css/style.css` 三主题样式、`js/` 框架层渲染逻辑。
> 说明：`index.html`、`toolpage.js`、`shell.js` 在抓取中被拦截，涉及这几个文件的改动项以 README 架构描述与 `app.js` 渲染逻辑推断为准，落地时按实际代码核对映射。

---

## 1. 背景与现状诊断

StackBench 功能底座扎实（零构建、本地优先、Ctrl+K 命令面板、收藏/最近、分享链接、三主题）。当前问题不在功能缺失，而在三个层面：

| 层面 | 现状问题 | 影响 |
|---|---|---|
| **布局** | 首页 26 个工具按 9 分类纵向平铺，hero 区偏小（h1 仅 22px），工具区要滚动很久才能到；顶栏搜索与侧边栏工具清单职责重叠 | 找工具成本高，首屏利用率低 |
| **视觉** | 默认赛博朋克主题霓虹粉 `#ff2ea6` + 三重发光阴影，视觉噪音大；图标用 emoji 文本字形（`{} ⇄ ⏱ 🔐` 等），跨平台渲染不一致；圆角 4/8/10/999px 混用无梯度 | 与"简洁、美观、大方"目标相悖，长时间使用疲劳 |
| **交互** | 命令面板缺键盘提示与匹配高亮；工具页输入/输出布局未统一；错误提示只走 toast，无行内定位；新用户无示例数据可一键体验 | "便于使用"的高频路径体验不完整 |

---

## 2. 整改目标（可验收）

| 目标 | 验收口径 |
|---|---|
| **便于使用** | 任意工具从打开站点到得到结果 ≤ 3 步；新用户不看文档能完成一次工具体验（示例数据一键填入） |
| **简洁** | 首页一屏内可达全部分类；同类视觉元素（圆角/间距/字号）收敛为统一 token，无重复入口 |
| **美观** | 默认主题为中性深色，emoji 全部替换为 SVG 线性图标，明暗三主题观感一致 |
| **大方** | 字号形成 3 级以上清晰层级，留白节奏统一 8px 梯度，hover/focus/active 状态齐全 |

---

## 3. 整改原则（不可突破的约束）

1. **零构建、零依赖、无 CDN**：不引 Google Fonts、不引图标库 npm 包；图标走内联 SVG（`icons.js` 映射），字体只优化系统字体栈。
2. **本地优先与安全约定不降级**：敏感工具不进分享链接、数据不上传等约定在 UI 文案中保留（可精简措辞）。
3. **三主题保留，只做"默认值调整 + 降噪"**：不删除赛博朋克主题，降级为可选彩蛋；默认切为中性深色。
4. **渐进增强，不重写框架层**：`registry.js` 注册协议、hash 路由、分享编码等通用逻辑零改动，整改集中在样式层与渲染模板层。

## 4. 整改内容

### 4.1 布局层

**A. 首页信息架构：长滚动 → 索引式**

- hero 区升级：标题提至 28–32px（`letter-spacing: -0.02em`），搜索框占位文案改"搜索 26 个工具… `Ctrl K`"，热门关键词行保留。
- "收藏"与"最近使用"合并为搜索框正下方的**一行双栏紧凑区**（收藏卡片 8 个上限不变、最近 chips 不变），不再与分类列表平级排底部。
- 9 个分类改为**分类筛选 Tab 行**（全部 / 数据格式 / 编码转换 / …，带工具计数徽标），选中即过滤下方网格；或在 ≥1024px 用左侧粘性分类目录 + 右侧网格二选一，以 Tab 方案为优先（实现成本低、响应式友好）。
- 网格维持 `repeat(auto-fill, minmax(260px, 1fr))`，卡片描述两行截断（`display:-webkit-box; -webkit-line-clamp:2; overflow:hidden`），去掉 `min-height:34px` 强制留白。
- 底部"安全约定"info-box 三行长文压缩为一行摘要 + `详情` 折叠展开。

**B. 工具页：统一三段式骨架**

```
面包屑 / 工具名 + 一句话说明 + [收藏|分享|重置]      ← 吸顶
┌──────────────┬──────────────┐
│   输入区(左)   │   输出区(右)  │  ← ≥960px 1:1 分栏，窄屏纵向堆叠
└──────────────┴──────────────┘
动作条 [运行] [填入示例] [清空]                      ← 贴输入区下方/吸底
```

- 输出区右上角复制按钮旁并列**下载 / 清空**图标按钮；复制成功给图标短暂变 ✓ 的微反馈。
- 输入区支持**拖拽文件与粘贴即填**（JSON、YAML、日志类工具优先）。
- 每个工具注册信息可选增加 `sample`（示例数据），工具页渲染"填入示例"按钮——新用户 3 秒看到效果。

**C. 顶栏 / 侧边栏职责去重**

- 顶栏收敛为：品牌 → 搜索（居中，max-width 520px 不变）→ 主题切换 → Agent 状态 → 设置。
- 侧边栏只保留：收藏、最近、分类目录（带计数），完整工具列表由首页网格与命令面板承担。
- 移动端抽屉补遮罩点击关闭 + 下滑关闭手势，搜索框固定抽屉顶部。

**D. 宽度与间距节奏**

- 首页 `max-width: 1080px` 维持；工具页分栏场景放宽至 `1280px`。
- 纵向间距统一 8px 梯度：`8 / 16 / 24 / 40`，替换现存 26px、12px、10px 混用；区块间距 40px、卡片间距 12→16px。

### 4.2 视觉层

**A. 主题默认值调整（P0，改动最小、收益最大）**

- `index.html` 默认 `data-theme` 由 `cyber` 改为 `dark`；首次访问跟随 `prefers-color-scheme` 选择 dark/light，用户手动选择后记入 localStorage。
- 赛博朋克降噪：去掉 70px 外发光，只留一档阴影；`--accent-2` 仅用于状态高亮，不作第二主色；小字号链接改用 `--accent-2` 或加下划线保对比度。

```css
:root[data-theme="cyber"] {
  --shadow: 0 0 0 1px #ff2ea622, 0 12px 32px rgba(255,46,166,.12);
  --accent: #ff2ea6; --accent-2: #00e7ff; /* 青色仅做状态高亮 */
}
```

- 主题切换入口从设置页提到顶栏图标按钮（三选一下拉或循环切换），切换时 `background/color/border-color` 加 `transition: .2s`。

**B. 设计 token 收敛（`style.css` 顶部统一定义）**

```css
:root {
  --radius-sm: 6px;   /* badge、输入框、kbd */
  --radius-md: 10px;  /* 卡片、面板 */
  --radius-lg: 16px;  /* 弹窗、hero 面板 */
  --radius-pill: 999px;
  --shadow-sm: 0 1px 2px rgba(0,0,0,.16);
  --shadow-md: 0 6px 24px rgba(0,0,0,.28);
  --fs-xs: 12px; --fs-sm: 13px; --fs-base: 14.5px;
  --fs-lg: 17px; --fs-xl: 22px; --fs-2xl: 30px;
  --space-1: 8px; --space-2: 16px; --space-3: 24px; --space-4: 40px;
}
```

**C. 字体与文字层级（系统字体栈，零 CDN）**

```css
:root {
  --font-sans: -apple-system, "SF Pro Text", "Segoe UI", "PingFang SC",
               "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif;
  --font-mono: "SF Mono", "JetBrains Mono", "Cascadia Code",
               Consolas, "PingFang SC", monospace;
}
```

- 正文 14px → 14.5–15px；11px 小字全部提到 12px 起；hero 标题 30px、区块标题 17px、卡片标题 14.5px，形成 ≥3 级层级。
- 代码、输入/输出、编辑区统一 `--font-mono`，字号 13–14px。

**D. 图标系统：emoji → 内联 SVG**

- 新增 `js/icons.js`：16/20px 线性 SVG（stroke-width 1.5–2，圆角端点），覆盖 9 个分类图标、搜索、收藏星标、复制、下载、清空、主题、设置、Agent 状态、最近（时钟）等全部 UI 图标。
- 现有 emoji（`{} ⇄ ⏱ 🔐 ¶ ⇢ ⚙ ◈ ✦ 🔍 🕘 ★`）全部替换；分类图标色只用 `--muted`，hover 变强调色。
- ⚠️ 禁止引入 FontAwesome 等第三方图标库或 CDN。

**E. 组件规范**

- 工具卡片 hover：变边框/背景之外，加 `transform: translateY(-2px)` + `--shadow-sm`，过渡 180ms ease；`:active` 加 `scale(.98)`。
- badge 体系：执行位置（浏览器/Worker/Agent）改**中性灰 + 左侧 6px 状态圆点**；仅"敏感"badge 保留红色描边——红色只用于警示。
- 收藏星标换 SVG 星形，填充/描边两态，色值 `#f5b942` 保留。

**F. 可访问性**

- 全部交互元素补 `:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }`（当前样式表缺失焦点态）。
- 赛博朋克主题小字号链接保证对比度 ≥ 4.5:1；所有 icon-only 按钮补 `aria-label`（部分已有，统一补齐）。

### 4.3 交互层

**A. 命令面板（Ctrl/Cmd + K）强化**

- 面板底部固定键盘提示行：`↑↓ 选择 · Enter 打开 · Esc 关闭`。
- 搜索命中关键词高亮（`--accent-weak` 背景）。
- 结果排序：最近使用 > 收藏 > 名称匹配 > 描述匹配；空输入时展示"最近 + 收藏 + 热门关键词"，不展示空列表。

**B. 全局快捷键约定（设置页加速查表）**

| 快捷键 | 行为 |
|---|---|
| `Ctrl/⌘ K` | 命令面板 |
| `Ctrl/⌘ Enter` | 当前工具执行/运行 |
| `Ctrl/⌘ ⇧ C` | 复制输出 |
| `Esc` | 关闭面板/抽屉/弹窗 |
| `?` | 快捷键帮助弹层 |

**C. 表单与反馈**

- 轻计算工具（JSON 格式化、颜色转换、Base64 等）实时处理，防抖 200ms；重计算（Diff、Worker 类）保留手动"运行"。
- 错误提示升级为**行内定位**：JSON 校验的错误行列在编辑区行号标红 + 行内提示，toast 仅作辅助。
- 破坏性操作（清空、重置）给 3 秒撤销 toast 或二次确认。
- Agent 类工具在 Agent 未启动时，**卡片即标注状态**（灰显 + "需本地 Agent"），点击给可复制的 `npm run agent` 启动命令，而非进页后才报错。

**D. 空状态与首访引导**

- 首访 hero 下方三步迷你引导（搜索 → 打开工具 → 收藏），localStorage 标记完成后自动消失。
- 收藏/最近为空时，空状态文案下给 3 个推荐工具快捷卡片，替代纯文字。

**E. 微动效**

- hash 路由换页：内容 `opacity 0→1` + `translateY(8px→0)`，150ms。
- 所有动效遵守 `prefers-reduced-motion: reduce` 时全部关闭。

|---|---|
| 工具 UI 文件较多（26 个），分栏/示例按钮改造面广 | 以"通用骨架 + 工具只填槽位"方式改 `toolpage.js`，工具文件仅补 `sample`；先覆盖 Top8 高频工具再批量 |
